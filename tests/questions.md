# 測試題庫

用來檢查「找得到正確的標準」與「AI 整理沒有超出原文」。每次改檢索參數（`config.asp` 第 4 節）、同義詞、模型或系統提示詞後，把整份題庫跑一遍並填「實測結果」。

## 欄位說明

| 欄位 | 填寫方式 |
|---|---|
| 編號 | 示範版 `D-01`…；正式版 `P-01`… |
| 題型 | 一般／縮寫俗稱（foley、NG）／口語描述／數值（時間、劑量、壓力）／應找不到／範圍外（個別病人處置） |
| 問題 | 實際輸入的句子，照護理師會問的方式寫 |
| 預期答案重點 | 標準原文中**必須出現**在回答裡的重點，數值照原文抄 |
| 應引用標準 | 標準編號＋頁碼，例 `CP901 p.2`；應找不到時填 `—` |
| 預期狀態 | `ok` 明確相關／`low` 可能相關／`nohit` 找不到 |
| 實測結果 | ✅ 通過／⚠ 部分（說明）／❌ 失敗（說明）；註明測試日期與模型 |

**判定原則**
- 「最相關的標準」或引用出處中有「應引用標準」→ 檢索通過。
- AI 回答涵蓋所有「預期答案重點」、沒有 ⚠ 數值警告、沒有原文以外的內容 → AI 通過。
- 應找不到的題目，系統必須回覆找不到，不可由 AI 自行回答。
